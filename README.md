# GeoParcel AI Frontend Prototype

Run:
1. Install Node.js.
2. Extract this folder.
3. Open a terminal in the folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the Vite local URL.

This is a frontend-only prototype. Parcel polygons/statistics are mock data. The UI is ready to connect to FastAPI/PostgreSQL/PostGIS later.
